# Finalizing Setup

With your SD Card back in your 3DS, power it back on. Go into System Settings, and then Nintendo Network ID Settings. You should now be here.

![First stage of Nintendo Network ID setup](/assets/img/guide/nnid1.png)

Press through the prompts until you get to here:

![Link or create a new ID](/assets/img/guide/haveid.png)

::: details If you already have a Samtendo Network ID

Choose `Link an Existing ID`, `Next`, `I Understand`, then fill out your information.

:::

Otherwise, choose `Create a New ID`, `Next`, `I Understand`, `View the Nintendo Network Agreement and Privacy Policy`, `I Accept`, `I Accept` again, then fill out your information.

Once your Samtendo Network ID has been linked, **congrats! You're now ready to start playing on Samtendo Network!**
